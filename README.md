# TallerPOO4
Un sistema académico integral que digitaliza y automatiza la gestión de  
certificaciones profesionales, proporcionando: 
• Transparencia: Los estudiantes ven en tiempo real su progreso, requisitos pendientes y 
proyección de completación. 
• Eficiencia: Los coordinadores acceden a dashboards analíticos que identifican patrones de 
rendimiento y asignaturas críticas. 
• Automatización: Generación instantánea de certificados oficiales cuando se cumplen los 
requisitos académico
